Chameleon - Privacy Policy

Last updated: November 18, 2026

Chameleon is a personal tool that runs only on its owner's own computer. It is used by its owner to publish their own short video clips to their own social media accounts.

What it accesses

When the owner connects an account, Chameleon receives an access token from that platform (Google/YouTube, TikTok or Meta/Instagram). It uses the token only to upload videos the owner has approved and to read the account's display name, so the owner can see which account is connected.

How data is stored

Tokens and settings are stored only in files on the owner's computer. Nothing is sent to any server operated by Chameleon - there is none. Videos go directly from the owner's computer to the platform the owner chose.

Sharing

Chameleon does not sell, share or transfer any user data to third parties, and does not use data for advertising.

YouTube API Services

Chameleon uses YouTube API Services. By using it you agree to the YouTube Terms of Service. See also the Google Privacy Policy.

Removing access

Access can be revoked at any time at Google security settings (or the matching settings page of TikTok or Instagram). Deleting Chameleon's secrets folder removes all stored tokens.
